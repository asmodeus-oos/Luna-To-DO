# Product Context: Luna

## Vision
Luna is an ultra-tactile, fluid personal task and focus manager built with Jetpack Compose. It blends physical hardware-inspired micro-interactions with high-end liquid glassmorphism, creating a serene yet responsive environment for getting things done.

## User Needs & Problem Statement
Traditional to-do apps are either overly utilitarian lists or cluttered enterprise project managers. Luna bridges the gap: it delivers the speed and simplicity of a minimalist checklist, augmented with tactile delight (spring physics, haptic pulses, harmonic chimes) and multiple visual representations (Kanban, Focus Timer, Calendar, Habits, Matrix, Analytics).

## Core Pillars
1. **Physicality & Tactility**: Every tap feels like pressing physical hardware. Checkboxes have spring inertia and ripple effects; completed tasks smoothly glide to the bottom without disorienting viewport jumps; buttons have tactile spring scales.
2. **Liquid Glass Aesthetic**: Translucent frosted surfaces, curved specular highlights, ambient shadows, and organic morphing liquid bubbles that fluidly slide across navigation targets.
3. **Cognitive Flexibility**: Seamlessly shift between high-level list flow, deep focus mode, board organization, habit tracking, and high-level productivity analytics.
4. **Focused Monochromatic Base with Warm Amber Light**: Rich off-white / `#E8E8E8` foundation in light mode, pitch `#000000` in AMOLED mode, with warm golden liquid glass accents on selected affordances.

## Primary Navigation Structure
- **Home / Flow**: Daily checklist, smart filter chips (All, Today, Urgent, Completed), tags, search, batch actions.
- **Focus & Habits**: Integrated countdown stopwatch, routine streaks, habit trackers, Pomodoro rings.
- **Projects & Kanban**: Kanban board columns, project folders, dependency hierarchies.
- **Settings & Preferences**: AMOLED / Dark / Light theme switching, sound and haptic tactile controls, data cleanup.
- **Search (Floating Glass Orb)**: Instant cross-app fuzzy search and filter overlay.
